# Blockie

A bootc image for the KONKR Pocket Block, built on Fedora (`registry.fedoraproject.org/fedora-bootc:44`).

CI builds `ghcr.io/seilent/blockie:testing-<sha>` from `main` and `ghcr.io/seilent/blockie:dev-<sha>` from other
branches. `testing` moves after a release check.
